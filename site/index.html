FAQ

What is Cashu, and what is a mint?

Cashu is an ecash protocol. A mint is a server that issues and redeems Cashu tokens. Auditorcillo ranks public mints by what it observes when it probes them, not by what they announce.

What does Auditorcillo check?

On every run it checks that keyset IDs derive from the published keys and that active keysets publish keys (NUT-02), and that the mint can create a mint quote (NUT-04) and a melt quote (NUT-05). If the mint announces NUT-07, it also checks token state. A full cycle — issuing tokens, DLEQ proofs, swaps, rejecting a spent token, paying a Lightning invoice and marking tokens as spent — runs on every probe on local FakeWallet mints, and once a day on real mints when a wallet is configured (other runs reuse each mint’s last paid result).

How often is the ranking updated?

A scheduled GitHub Action runs public checks and updates uptime about every 3 hours, runs the paid cycle on real mints once a day (12:17 UTC / 09:17 Buenos Aires time), and publishes a new ranking.json.

What does “possible fraud” mean?

A mint is flagged and its score is set to 0 if it accepts an already spent token, or if its keyset IDs do not derive from its published keys.
